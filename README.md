**HabitSpark** is a premium, glassmorphic habit-tracking application designed to help you ignite and maintain a healthy lifestyle. With real-time analytics, gamified progress, and a sleek modern UI, tracking your goals has never looked this good.

---

## 🚀 Features

- **💎 Glassmorphic UI**: A stunning, modern interface with vibrant colors and smooth animations.
- **📊 Advanced Analytics**: High-density dashboards, contribution heatmaps, and radar charts to track your progress.
- **⚡ Real-time Sync**: Powered by Firebase for instant data updates across all your devices.
- **🎯 Smart Reminders**: Customizable notifications to keep you on track with your goals.
- **📱 Multi-platform**: Support for Android, iOS, and Web.

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev)
- **Backend**: [Firebase](https://firebase.google.com) (Auth, Firestore, Storage)
- **State Management**: Provider / Service Pattern
- **Charts**: [fl_chart](https://pub.dev/packages/fl_chart)
